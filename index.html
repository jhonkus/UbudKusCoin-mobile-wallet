Why UbudKusCoin Wallet?

Hold and transact UKC directly on the UKC testnet from your mobile device. No third-party wallet backend — the app integrates directly with the UKC protocol and node API.

🔐

Secure Wallet

Create or open a wallet from a BIP-39 seed phrase, protected by a 6-digit PIN with constant-time verification.

📊

Live Dashboard

View your account balance and live transaction history, refreshed with pull-to-refresh.

✈️

Send UKC

Send to any UKC address with amount & fee validation and on-device signing of the canonical KTX2 envelope.

📥

Receive & Scan

Share your wallet address or scan a UKC QR code to instantly pre-fill the send form.

🧾

Transaction Detail

Review full details and live on-chain status of any transaction, including fee, nonce and block height.

⛓️

Direct Protocol Access

Derives accounts at m/0, builds Base58Check addresses, signs secp256k1 DER signatures and submits via CometBFT.

Getting Started

Clone the repo and run the app on your local Android emulator or iOS simulator.

1

Install tooling

Install Android Studio, Node.js (v16+), Java, and Watchman.
2

Clone & install

git clone git@github.com:jhonkus/UbudKusCoin-mobile-wallet.git yarn install
3

Start Metro & run

yarn start yarn android yarn ios
4

Run tests & lint

yarn test yarn lint

Security & Design

Built with security-conscious defaults during this active-development phase, targeting the UKC testnet.

Auto-lock Locks the session on background and prompts for your PIN on return.
Constant-time PIN PIN verification uses a constant-time comparison to reduce timing side channels.
In-memory seed The seed phrase is kept only in a locked in-memory session — never in Redux or navigation state.
Dev-only endpoints HTTP testnet defaults are development-only. A real deployment must use HTTPS and a restricted RPC.
